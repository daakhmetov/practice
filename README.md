# Monitoring

Веб-приложение для демонстрационного мониторинга вендинговых автоматов VBox.

## Требования

- Node.js 20 или выше
- MongoDB

## Установка

```bash
npm install
```

Создайте файл `.env` в корне проекта:

```env
PORT=3000
MONGO_URI=
```

## Запуск

```bash
npm start
```

Для запуска в режиме разработки:

```bash
npm run dev
```

После запуска интерфейс доступен по адресу:

```text
http://localhost:3000
```

## Заполнение базы демо-данными

Откройте в браузере:

```text
http://localhost:3000/api/seed
```

Метод `seed` удаляет текущие записи автоматов и добавляет четыре демонстрационные записи:

| ID | Адрес | Статус | Остаток напитков | Вместимость | Выручка |
| --- | --- | --- | --- | --- | --- |
| VBOX-001 | Алматы, Адрес 1 | Online | 95 | 100 | 32000 |
| VBOX-002 | Алматы, Адрес 2 | Online | 15 | 100 | 45000 |
| VBOX-003 | Астана, Адрес 3 | Error | 0 | 100 | 12000 |
| VBOX-004 | Шымкент, Адрес 4 | Offline | 40 | 100 | 0 |

## API

### Получить список автоматов

```http
GET /api/machines
```

Поддерживаются query-параметры:

- `status`: `Online`, `Offline` или `Error`
- `search`: поиск по ID автомата или адресу

### Получить статистику дашборда

```http
GET /api/dashboard/stats
```

Возвращает общее количество автоматов, количество онлайн-автоматов, количество автоматов с ошибкой и суммарную выручку.

### Пополнить автомат

```http
POST /api/machines/:id/restock
```

Устанавливает `drinksCount` равным `maxCapacity`. Если автомат был в статусе `Error`, статус меняется на `Online`.

### Инкассировать автомат

```http
POST /api/machines/:id/collect-cash
```

Устанавливает `revenue` равным `0`.

### Заполнить базу демо-данными

```http
GET /api/seed
```

Пересоздает демонстрационный набор автоматов.
